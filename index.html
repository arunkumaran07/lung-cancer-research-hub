    About this hub

    Maintained by Arun Kumaran Anguraj Vadivel, Toronto. This page is a research reference, not medical advice; people looking for a trial should discuss options with their care team.

    How the data are gathered

    Every morning a GitHub Action runs refresh.py, which queries the ClinicalTrials.gov API for … with status recruiting or not yet recruiting, and PubMed for the searches below. Trials that leave recruitment drop off the table at the next refresh. Papers stay in the feed for 120 days after PubMed adds them. The curated sections are edited by hand in curated.json.

      Limits

      ClinicalTrials.gov is the largest registry but not the only one; some Canadian and international studies are listed only in other registries. Automatic tags can miss or mislabel studies, especially basket trials that enrol several tumour types. Publication-type tags in PubMed are added during indexing, so the newest trial reports and guidelines can take several weeks to appear.

      Data from ClinicalTrials.gov (U.S. National Library of Medicine) and PubMed. Source code and change history are on GitHub.
